# Restful Booker - Manual API Testing Project

## Project Overview

This project demonstrates a **Manual API Testing** approach performed on the **Restful Booker API**.

The project focuses on testing RESTful API endpoints, validating request and response behavior, verifying authentication, checking response status codes, and identifying functional defects.

The project includes API test planning, test scenarios, test cases, defect reporting, Postman collections, and authentication documentation.

---

## Application Under Test

**Restful Booker API**

Restful Booker is a demo API designed for practicing API testing and automation.

The API provides functionality for managing hotel booking information and includes endpoints for authentication, booking creation, booking retrieval, booking updates, and booking deletion.

---

## Project Objectives

- Understand the Restful Booker API.
- Analyze API requirements and behavior.
- Design API test scenarios.
- Create detailed API test cases.
- Execute API requests using Postman.
- Validate HTTP response status codes.
- Validate response body and response data.
- Validate request parameters and payloads.
- Test authentication functionality.
- Identify and document API defects.
- Maintain reusable Postman API collections.
- Prepare structured QA documentation.
